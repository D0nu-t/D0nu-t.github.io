PolicySwarm — AI Governance
Policy Simulator

Motivation

AI governance policy is designed using intuitions about how populations respond to rules, shocks and media. Those intuitions are rarely tested computationally. PolicySwarm builds a simulation environment where you can vary one parameter, hold everything else fixed, and observe how a synthetic social network evolves.

What it is and isn't: this is mechanism exploration, not prediction. The claims take the form "if a social system works like this model, then…". The model is not calibrated to real-world data.

Architecture Built — code on GitHub

A Python package that takes a policy text, turns it into a four-dimensional policy vector, and runs a bounded-confidence opinion model on a scale-free network. In bounded-confidence models, agents only influence each other when their opinions are already close enough.

Method

  • Centred opinion space. Opinions live in [-1, 1]4 with 0 as neutral, so the angle between two agents measures how aligned they are.
  • Matched thresholds. The same threshold number means different things under different distance metrics. Each geometry's threshold is calibrated so that it admits the same share of neighbouring pairs at the start of a run.
  • Paired runs. Treatment and control share a seed, with separate random streams for initialisation, shock targets and policy noise, so the difference between them is the effect of the intervention.
  • Reported pass rate. Every run records how often agent pairs actually passed the threshold, because matched starting conditions drift apart during a run.

Results

Three results from the 30-seed runs with matched thresholds:

Opinion variance, no media 0.016 Peers and policy alone leave opinions tightly grouped. Baseline
Opinion variance, with media 0.086 Ideology-aligned media spreads opinions about 5.5× wider. Media on
  • Who a shock hits matters. The same shock raises opinion variance when it targets high-degree hubs and lowers it when it targets random agents.
  • Media widens opinion spread, from 0.016 to 0.086 in opinion variance.
  • Peer influence acts differently by geometry. Under Euclidean distance, stronger peer influence lowers variance (0.097 → 0.074). Under cosine and manifold distance it has almost no effect, because angular steps change an agent's direction and not how strongly it holds the opinion.

A practical lesson: a distance metric is a modelling commitment. Comparing metrics is only fair once their thresholds are matched; otherwise one metric can end up with almost no threshold at all.

Goals

  • Paper revision — rewrite around the results above.
  • Enforcement design — rework who counts as a violator and what a penalty does, so enforcement can be studied on its own.
  • Agent heterogeneity — role-based agents (regulators, industry, civil society).
  • Hyperbolic geometry — a natural fit for hierarchical, scale-free networks.
